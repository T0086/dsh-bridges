# dsh-bridges

> 作者：空游

把外部世界接进同一个会话的 DSH 插件（Discord / QQ / 语音）

## 包含

- discord-bridge：Discord 私信/频道与会话互通，Gateway 推送优先、REST 轮询兜底
- qq-bridge：MuMu 模拟器读屏，QQ 消息与会话互通
- voice-talk：右 Alt 按住说话，本地转写后进剪贴板

## 安装

每个子目录都是独立的 DSH bundle，分别安装：

    plugin_manager install_bundle "<path>\<subdir>"
